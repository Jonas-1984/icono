1. Installing, starting, uninstalling

Requirements

  • Windows 10 (version 1809 or newer) or Windows 11, 64-bit.
  • About 200 MB of free space. Everything needed (including .NET) is part of the installer; no internet is needed.

Install

  1. Double-click ICONO-Setup-0.1.0-test.4.exe.
  2. If Windows shows “Windows protected your PC” (SmartScreen), that is normal for this test version: it is not digitally signed yet. Check that the file comes from your contact (checksum in SHA256.txt), then choose “More info” → “Run anyway”.
  3. Choose a language, read and accept the test terms and the privacy notice. No administrator rights are needed; the installation is for your user account only.
  4. An older test version is replaced; your settings and drawings are kept.

Check the checksum (optional)

In PowerShell: Get-FileHash .\ICONO-Setup-0.1.0-test.4.exe -Algorithm SHA256. The value must match SHA256.txt.

Start

Start menu → icono (or the desktop shortcut, if you chose one). A start screen plays for six seconds; a click or a key skips it. The start parameter --no-splash skips it too.

Uninstall

Windows Settings → Apps → icono → Uninstall (or Start menu → “Uninstall icono”). The uninstaller asks whether your local data (settings, recent files, icon library, error log) should be deleted too. Your saved drawings are always kept.

3. Document, pages and scale

New, open, save

  • File → New (Ctrl+N), Open (Ctrl+O), Save (Ctrl+S), Save As (Ctrl+Shift+S).
  • The file format is .icn. Older files ending in .icono still open.
  • With the file association (the installer asks; on by default) your drawings carry the icono file icon and a double click on an .icn file in Explorer opens it in icono. Uninstalling removes the association again.
  • When you close with unsaved changes, icono asks (save / discard / cancel).
  • For safety icono does not open documents over 512 MB or pictures over 64 MB (see Security).

Pages

A drawing can have several pages of the same size, one below the other. Page → Add Page / Remove Last Page / Pages… or the PAGES card. The mouse wheel scrolls through the pages (Shift+wheel sideways). Page → Size offers A5, A4, A3, Letter and pixel sizes (64 to 512 px), custom sizes (CANVAS SIZE card) and portrait/landscape.

Unit

CANVAS SIZE card → UNIT: px, cm, mm, inch. It applies to the rulers and to new dimensions; every dimension can also have its own unit.

The scale belongs to the page

The scale (for example 1:40) says how much reality one centimetre of the page stands for. Set it in CANVAS SIZE → SCALE (pick one or type a number, then Enter).

Changing the scale keeps all measurements. If you go from 1:40 to 1:50, the drawing becomes 40 : 50 as big on the page (about the middle of the page it lies on) and every dimension keeps its value. Wall thicknesses keep their real size. What belongs to the paper stays: line weights, text sizes, arrowhead sizes and the distance of dimension lines. The whole change is one undo step. Icon grids (Design Grid) are not affected.

To print a plan at the exact scale, print at 100 % (see Export and printing).

Layers and background

Page → New Layer adds a layer; layers can be hidden or locked. Page → Background… (BACKGROUND card): transparent, colour (with the colour picker), blur or image. Page → Sheet Data… adds a title block with a frame (project, address, date, scale from the page).

4. Drawing: shapes, lines, handwriting, text

  • Shapes (Insert → Shape or the SHAPES card): rectangle, ellipse, triangle, star, heart, arrows, 3D box and many symbols. Drag with the mouse. Corner handles keep the proportions, Shift frees them.
  • Lines (Draw → Line, Arrow, Double Arrow, Polyline, Curve): click point by point; double-click or Enter finishes, Esc cancels. Options (dash, arrowheads, length, rounded corners, sketch style) are in the LINE card and in the small box next to a clicked line.
  • Handwriting (P or the orange key top left): write and draw with an e-pen, a finger (touch) or the mouse. Every stroke is its own object. Colour, width and SMOOTHING (0–10, hand tremor is smoothed out) are in the HANDWRITING card. Esc ends.
  • Curve (tool “Curve” in the TOOLS card): round the corners of lines and shapes – click one side, click the neighbouring side, type the size, Enter.
  • Text (T): click and type. Double-click a shape to type into it. Format and alignment in Design → Text Formats….
  • Images and SVG (Insert → Image… / SVG Code…): insert pictures and SVG graphics (SVG as code or from a file).

5. Floor plans: walls, rooms, doors, objects

Walls

  • Draw a wall (W): click the corners. Or type a length and press Enter: the corner is placed in the direction of the mouse. The typed length is the inside length (the clear length in the room). Enter without a number ends, Esc cancels. New walls are 15 cm thick at the chosen scale.
  • Insert a room: Draw → Add Room (closed room, L-shape, slanted walls, columns).
  • Change a length: click the number of a wall dimension, type the length you want (for example 250, 2.5 m, 2500 mm), Enter.
  • Edit: drag corners, cut walls (X), join, straighten, close a room (Draw menu, WALL card: thickness, hatch, unit, measure inside/centre/outside, show dimensions).

Doors and windows

Insert → Door and Window puts a door, double door, window, double window or wall opening on a wall; they cut the wall open. Rotation, flip, opening angle and wall thickness are in the OPENING card. Their dimensions (width of the opening and clear distance to the wall corners) can be shown; click a number and type a new length to slide the element along the wall.

Objects and furniture

The OBJECTS card holds plan symbols (sockets, appliances, sanitary …), cabinets and kitchen elements and computers at real size. Groups fold open and shut; the search box filters all groups. Click an object, then click the drawing; it appears at its real size at the current scale.

6. Dimensions

Free dimensions

Draw → Dimension (D): aligned, horizontal, vertical, angle, radius, diameter. Click the measured points, then once where the dimension line should run. The points snap to objects and stay attached to them. Add Dimensions to Selection adds dimensions to the selected shape automatically (width/height/depth, diameter, corners, segments).

Placing dimensions of walls, doors and windows – with the mouse only

  • Click the number (without dragging): the length input opens.
  • Drag the number: the dimension line follows the mouse, on either side of the wall and at any distance. Let go and it stays. Esc while dragging puts it back; Ctrl+Z undoes it afterwards.
  • There are no separate fields for “inside/outside” or “distance”: the mouse alone decides side and distance.

Lining up in one row

While you drag (or when you place a free dimension line) the line snaps onto the line of another dimension that runs the same way as soon as it is within reach (about 8 screen pixels). A dashed orange guide shows what it lines up with, so chains of dimensions stand flush in one row. This works between dimensions of the same wall, of different walls, of doors/windows and free dimensions. Alt switches snapping off.

Every dimension has its own settings

In the DIMENSION card (right) you set unit, decimal places, text, position and distance of the number, number size, line width, arrow style and size and extension lines. For walls pick the dimension to change under “WHICH DIMENSION” (by default the one whose number you last clicked or dragged). A setting only affects that one dimension – not the other dimensions of the wall and not new dimensions.

Carrying a style over with Match

The Match tool (Q or the paint roller in the TOOLS card) copies the look of one object to others: pick the source, switch the tool on, then click the targets. If you click the number of a dimension, only its style is carried over – also from one dimension to another of the same wall. Ctrl+click picks a new source. The button “Dimension style to ALL dimensions” deliberately copies a style to all.

7. Snapping and alignment

  • Object snap (F3 on/off, OBJECT SNAP card): end points, middles, centres, crossings, perpendicular, tangent, nearest and more. An orange mark and a short name show the snap.
  • Alignment (ALIGN WHILE MOVING card): while moving, the selection lines up with faces, edges and middles of other objects; guides show it.
  • Grid: grid size in the field at the right of the toolbar (cm); grid snap with the grid key.
  • Hold Alt: no snapping for this one move.
  • Snapping also applies to dimensions: when placing them, when dragging the dimension line and when moving their points.

8. Editing and tools

  • Select: click, Shift+click (several), drag a frame (to the right = everything fully inside; to the left = everything it touches), Ctrl+A.
  • Move: drag, arrow keys (10 px with Shift) or Arrange → Move… (MOVE card: distance in cm in X and Y). Align/distribute, flip, rotate are in the Arrange menu.
  • Group / lock: Ctrl+G, Ctrl+Shift+G; locked objects cannot be changed. Front/back in the Arrange menu.
  • Edit points: select an object and drag its points; tools Add Point / Delete Point in the TOOLS card (the mouse cursor shows the tool’s icon).
  • Combine: Union, Trim, Reflect, Offset, Merge to One Shape, Explode (Ctrl+Shift+X) in the Arrange menu.
  • Colour picker (I): take a colour from the page. Bucket / Region Color (G): colour a closed area.
  • Copy/paste with Ctrl+C/X/V or the keys in the TOOLS card; Ctrl+D duplicates.
  • Undo / redo: Ctrl+Z / Ctrl+Y. Almost every change is a step of its own.

9. View, zoom, themes

  • Zoom: slider bottom left, Ctrl+mouse wheel, Ctrl++ / Ctrl+-, Ctrl+0 (100 %), Ctrl+1 (fit page).
  • Zoom tool (Z or the magnifier in the TOOLS card): left click = +10 %, right click = −10 %; the clicked point stays where it is. Esc ends.
  • Moving the view: Pan tool (H) or the middle mouse button.
  • Rulers: View → Show Rulers. They show real-world size at the scale of the drawing.
  • Themes (View → Theme): dark and light, each flat or as glass. Your choice is saved.

12. Files, data and privacy

icono sends nothing. The program does not connect to the internet on its own, has no usage statistics, no advertising, no sign-in and no cloud requirement. It does not use the camera, microphone or location.

WhatWhere
Your drawingsOnly where you save them (File → Save / Export).
Settings and lists%LocalAppData%\Icono (Windows key+R, type the path): theme.txt (your theme), recent.txt (recent files), Library\ (your icon library), crash.log (error log).

The error log crash.log is only written when an unexpected error occurs and can contain file names or paths. It stays on your device; send it only voluntarily when you report a problem, and look through it first. You can delete the folder at any time.

The entries Check for Updates, Website and Contact in the Help menu open your browser or e-mail program when you click them; only then a connection is made, by those programs. The manual, the test terms and the privacy notice open locally from the installation folder in your default web browser (no internet).

If your drawings contain personal data of third parties (for example names in a title block), you are responsible for handling it. Do not send such drawings to the maker.

The full privacy notice is Privacy.txt in the installation folder (also shown during installation).

13. Security

  • No network access by the program; no background services.
  • Files from outside are untrusted data: SVG files are read without a DTD and without entities (protection against “billion laughs” and reading local files); nothing is loaded from disk or network. SVG up to 20 MB, documents up to 512 MB and pictures up to 64 MB are accepted, larger ones are refused.
  • Only fixed addresses are opened (project page, bitbins.de, the contact mail), never addresses from documents.
  • The installer is not signed (test version): check where it came from and the checksum (SHA-256). Only get icono from your contact.
  • Please report security problems confidentially to info@bitbins.de (see also SECURITY.md in the project).
