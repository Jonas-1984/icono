1. Installation, Start, Deinstallation

Voraussetzungen

  • Windows 10 (Version 1809 oder neuer) oder Windows 11, 64 Bit.
  • Rund 200 MB freier Speicher. Alles Nötige (auch .NET) ist im Installationsprogramm enthalten, es wird kein Internet gebraucht.

Installieren

  1. ICONO-Setup-0.1.0-test.4.exe doppelt anklicken.
  2. Zeigt Windows „Der Computer wurde durch Windows geschützt“ (SmartScreen), ist das bei dieser Testversion normal: Sie ist noch nicht digital signiert. Prüfen Sie, dass die Datei von Ihrem Ansprechpartner kommt (Prüfsumme siehe SHA256.txt), und wählen Sie „Weitere Informationen“ → „Trotzdem ausführen“.
  3. Sprache wählen, die Testbedingungen und den Datenschutzhinweis lesen und annehmen. Es werden keine Administratorrechte gebraucht, die Installation gilt nur für Ihr Benutzerkonto.
  4. Eine ältere Testversion wird dabei ersetzt, Ihre Einstellungen und Zeichnungen bleiben erhalten.

Prüfsumme prüfen (optional)

In PowerShell: Get-FileHash .\ICONO-Setup-0.1.0-test.4.exe -Algorithm SHA256. Der Wert muss mit SHA256.txt übereinstimmen.

Starten

Startmenü → icono (oder die Desktop-Verknüpfung, falls gewählt). Beim Start läuft sechs Sekunden ein Ladebildschirm; ein Klick oder eine Taste überspringt ihn. Mit dem Startparameter --no-splash entfällt er.

Deinstallieren

Windows-Einstellungen → Apps → icono → Deinstallieren (oder Startmenü → „icono deinstallieren“). Das Programm fragt, ob auch Ihre lokalen Daten (Einstellungen, zuletzt geöffnete Dateien, Icon-Bibliothek, Fehlerprotokoll) gelöscht werden sollen. Ihre gespeicherten Zeichnungen bleiben in jedem Fall erhalten.

3. Dokument, Seiten und Maßstab

Neu, öffnen, speichern

  • File → New (Ctrl+N): neue Zeichnung. Open (Ctrl+O), Save (Ctrl+S), Save As (Ctrl+Shift+S).
  • Das Dateiformat heißt .icn. Ältere Dateien mit der Endung .icono lassen sich weiter öffnen.
  • Mit der Dateizuordnung (der Installer fragt danach, Standard: an) tragen Ihre Zeichnungen das icono-Dateisymbol, und ein Doppelklick auf eine .icn-Datei im Explorer öffnet sie in icono. Beim Deinstallieren wird die Zuordnung wieder entfernt.
  • Beim Schließen mit ungespeicherten Änderungen fragt icono nach (Speichern / Verwerfen / Abbrechen).
  • Zur Sicherheit öffnet icono keine Dateien über 512 MB und keine Bilder über 64 MB (siehe Abschnitt Sicherheit).

Seiten

Eine Zeichnung kann mehrere Seiten gleicher Größe haben, die untereinander liegen. Page → Add Page / Remove Last Page / Pages… oder die Karte PAGES. Das Mausrad blättert durch die Seiten (Shift+Rad seitwärts). Page → Size bietet A5, A4, A3, Letter und Pixelgrößen (64 bis 512 px) sowie eigene Größen (Karte CANVAS SIZE) und Hoch-/Querformat.

Maßeinheit

Karte CANVAS SIZE → UNIT: px, cm, mm, inch. Die Einheit gilt für die Lineale und für neue Maße; jede Dimension kann zusätzlich ihre eigene Einheit haben.

Der Maßstab (Scale) gehört zur Seite

Der Maßstab (zum Beispiel 1:40) sagt, wie viel Wirklichkeit ein Zentimeter der Seite darstellt. Sie stellen ihn unter CANVAS SIZE → SCALE ein (Auswahl oder eigene Zahl, dann Enter).

Beim Ändern des Maßstabs bleiben alle Maße gleich. Wechseln Sie von 1:40 auf 1:50, wird die Zeichnung auf der Seite im Verhältnis 40 : 50 kleiner (um die Mitte der Seite, auf der sie liegt), und jede Dimension zeigt weiter denselben Wert. Wandstärken behalten ihre wirkliche Größe. Was zum Papier gehört, bleibt unverändert: Strichstärken, Schriftgrößen, Pfeilgrößen und der Abstand der Maßlinien. Der ganze Vorgang ist ein einziger Rückgängig-Schritt. Raster für Icons (Design Grid) sind davon nicht betroffen.

Zum Drucken im genauen Maßstab drucken Sie mit 100 % (siehe Export und Druck).

Ebenen und Hintergrund

Page → New Layer legt eine Ebene an; Ebenen können sichtbar/unsichtbar und gesperrt sein. Page → Background… (Karte BACKGROUND): transparent, Farbe (mit Farbwähler), Unschärfe oder Bild. Page → Sheet Data… fügt einen Plankopf mit Rahmen hinzu (Projekt, Adresse, Datum, Maßstab aus der Seite).

4. Zeichnen: Formen, Linien, Handschrift, Text

  • Formen (Insert → Shape oder Karte SHAPES): Rechteck, Ellipse, Dreieck, Stern, Herz, Pfeile, 3D-Box und viele Symbole. Aufziehen mit der Maus. Eckgriffe halten die Proportionen, mit Shift frei.
  • Linien (Draw → Line, Arrow, Double Arrow, Polyline, Curve): Klicken Sie Punkt für Punkt; Doppelklick oder Enter beendet, Esc bricht ab. Optionen (Strichart, Pfeilköpfe, Länge, Rundung von Ecken, Skizzenstil) in der Karte LINE und im kleinen Fenster, das neben einer angeklickten Linie erscheint.
  • Handschrift (P oder die orange Taste links oben): schreiben und zeichnen mit E-Pen, Finger (Touch) oder Maus. Jeder Strich ist ein eigenes Objekt. Farbe, Breite und SMOOTHING (0–10, Zittern wird herausgerechnet) stellen Sie in der Karte HANDWRITING ein. Esc beendet.
  • Rundung (Werkzeug „Curve“ in der Karte TOOLS): Ecken von Linien und Formen abrunden – Seite anklicken, Nachbarseite anklicken, Größe eintippen, Enter.
  • Text (T): klicken und schreiben. Doppelklick auf eine Form schreibt Text in die Form. Format und Ausrichtung in Design → Text Formats….
  • Bilder und SVG (Insert → Image… / SVG Code…): Bilder und SVG-Grafiken einfügen (SVG auch als Code einfügen oder aus einer Datei laden).

5. Grundrisse: Wände, Räume, Türen, Objekte

Wände

  • Wand zeichnen (W): Ecken anklicken. Oder eine Länge eintippen und Enter drücken: die Ecke wird in der Richtung der Maus gesetzt. Die getippte Länge ist das Innenmaß (die freie Länge im Raum). Enter ohne Zahl beendet, Esc bricht ab. Neue Wände sind im gewählten Maßstab 15 cm dick.
  • Raum einfügen: Draw → Add Room (geschlossener Raum, L-Form, schräge Wände, Säulen).
  • Länge ändern: Auf die Zahl einer Wanddimension klicken, die gewünschte Länge tippen (zum Beispiel 250, 2.5 m, 2500 mm), Enter.
  • Bearbeiten: Ecken ziehen, Wände schneiden (X), verbinden, geradeziehen, einen Raum schließen (Draw-Menü, Karte WALL: Dicke, Schraffur, Maßeinheit, Messart innen/Mitte/außen, Dimensionen zeigen).

Türen und Fenster

Insert → Door and Window legt Tür, Doppeltür, Fenster, Doppelfenster oder Wandöffnung auf eine Wand; sie schneiden die Wand auf. Drehen, spiegeln, Öffnungswinkel und Wanddicke stehen in der Karte OPENING. Ihre Maße (Breite der Öffnung und lichter Abstand zu den Wandecken) lassen sich anzeigen; ein Klick auf eine Zahl und eine neue Länge verschiebt das Element entlang der Wand.

Objekte und Möbel

Die Karte OBJECTS enthält Plansymbole (Steckdosen, Geräte, Sanitär …), Schränke und Elemente sowie Computer in echter Größe. Gruppen lassen sich auf- und zuklappen, das Suchfeld filtert alle Gruppen. Klicken Sie ein Objekt an und dann auf die Zeichnung; es erscheint in seiner wirklichen Größe im aktuellen Maßstab.

6. Maße (Dimensionen)

Freie Dimensionen

Draw → Dimension (D): ausgerichtet, horizontal, vertikal, Winkel, Radius, Durchmesser. Sie klicken die Messpunkte und dann einmal dorthin, wo die Maßlinie laufen soll. Die Punkte rasten an Objekten ein und bleiben mit ihnen verbunden. Add Dimensions to Selection setzt Maße automatisch an die ausgewählte Form (Breite/Höhe/Tiefe, Durchmesser, Ecken, Segmente).

Maße an Wänden, Türen und Fenstern platzieren – nur mit der Maus

  • Zahl anklicken (ohne Ziehen): die Längeneingabe öffnet sich.
  • Zahl ziehen: Die Maßlinie folgt der Maus, auf beiden Seiten der Wand und in jedem Abstand. Beim Loslassen bleibt sie liegen. Esc während des Ziehens setzt sie zurück; Ctrl+Z danach macht es rückgängig.
  • Eigene Felder für „innen/außen“ oder „Abstand“ gibt es nicht mehr: Seite und Abstand bestimmt allein die Maus.

In einer Reihe bündig ausrichten

Beim Ziehen (oder beim Setzen einer freien Maßlinie) rastet die Maßlinie auf der Linie einer anderen Dimension ein, die in dieselbe Richtung läuft, sobald sie in Reichweite ist (etwa 8 Bildschirmpixel). Eine orange gestrichelte Hilfslinie zeigt, woran sie sich ausrichtet. So stehen Maßketten bündig in einer Reihe. Das gilt zwischen Dimensionen derselben Wand, verschiedener Wände, von Türen/Fenstern und freien Dimensionen. Alt hält das Einrasten aus.

Jede Dimension hat ihre eigenen Einstellungen

In der Karte DIMENSION (rechts) stellen Sie Einheit, Nachkommastellen, Text, Position und Abstand der Zahl, Zahlgröße, Linienstärke, Pfeilform und -größe sowie Hilfslinien ein. Bei Wänden wählen Sie unter „WHICH DIMENSION“ die Dimension, die sich ändern soll (Standard ist die Dimension, deren Zahl Sie zuletzt angeklickt oder gezogen haben). Eine Einstellung wirkt nur auf diese eine Dimension, nicht auf die anderen der Wand und nicht auf neue Dimensionen.

Stil übertragen mit Match

Das Werkzeug Match (Q oder Farbwalze in der Karte TOOLS) überträgt das Aussehen von einem Objekt auf andere: Quelle auswählen, Werkzeug einschalten, dann die Ziele anklicken. Klicken Sie die Zahl einer Dimension an, wird nur deren Stil übertragen – auch von einer Dimension auf eine andere derselben Wand. Mit Strg+Klick wählen Sie eine neue Quelle. Die Schaltfläche „Dimension style to ALL dimensions“ überträgt einen Stil ausdrücklich auf alle.

7. Fangen und Ausrichten

  • Objektfang (F3 ein/aus, Karte OBJECT SNAP): Endpunkte, Mitten, Zentren, Schnittpunkte, Lote, Tangenten, nächster Punkt und mehr. Eine orange Marke und ein Kurzname zeigen den Fang.
  • Ausrichtung (Karte ALIGN WHILE MOVING): Beim Verschieben richtet sich die Auswahl an Flächen, Kanten und Mitten anderer Objekte aus; Hilfslinien zeigen es.
  • Raster: Rasterweite im Feld rechts in der Symbolleiste (cm); Rasterfang mit der Rastertaste.
  • Alt gedrückt halten: kein Fangen für diese eine Bewegung.
  • Das Fangen gilt auch für Dimensionen: beim Setzen, beim Ziehen der Maßlinie und beim Verschieben ihrer Punkte.

8. Bearbeiten und Werkzeuge

  • Auswählen: Klick, Shift+Klick (mehrere), Rahmen aufziehen (nach rechts = alles, was ganz im Rahmen liegt; nach links = alles, was ihn berührt), Ctrl+A.
  • Verschieben: ziehen, Pfeiltasten (10 px mit Shift) oder Arrange → Move… (Karte MOVE: Abstand in cm in X und Y). Ausrichten/Verteilen, Spiegeln, Drehen im Menü Arrange.
  • Gruppieren / Sperren: Ctrl+G, Ctrl+Shift+G; gesperrte Objekte lassen sich nicht verändern. Vorne/hinten im Menü Arrange.
  • Punkte bearbeiten: Ein Objekt auswählen und Punkte ziehen; Werkzeuge Add Point / Delete Point in der Karte TOOLS (der Mauszeiger zeigt das Symbol des Werkzeugs).
  • Zusammenführen: Union, Trim, Reflect, Offset, Merge to One Shape, Explode (Ctrl+Shift+X) im Menü Arrange.
  • Farbwähler (I): eine Farbe von der Seite aufnehmen. Eimer / Region Color (G): einen geschlossenen Bereich einfärben.
  • Kopieren/Einfügen mit Ctrl+C/X/V oder den Tasten in der Karte TOOLS; Ctrl+D dupliziert.
  • Rückgängig / Wiederholen: Ctrl+Z / Ctrl+Y. Fast jede Änderung ist ein eigener Schritt.

9. Ansicht, Zoom, Designs

  • Zoom: Regler unten links, Ctrl+Mausrad, Ctrl++ / Ctrl+-, Ctrl+0 (100 %), Ctrl+1 (Seite einpassen).
  • Zoom-Werkzeug (Z oder die Lupe in der Karte TOOLS): Linksklick = +10 %, Rechtsklick = −10 %; der angeklickte Punkt bleibt an seiner Stelle. Esc beendet.
  • Verschieben der Ansicht: Werkzeug Pan (H) oder mittlere Maustaste.
  • Lineale: View → Show Rulers. Sie zeigen die wirkliche Größe im Maßstab der Zeichnung.
  • Designs (View → Theme): dunkel und hell, jeweils flach oder als Glas. Die Wahl wird gespeichert.

12. Dateien, Daten und Datenschutz

icono sendet nichts. Das Programm verbindet sich von sich aus nicht mit dem Internet, hat keine Nutzungsstatistik, keine Werbung, keine Anmeldung und keinen Cloud-Zwang. Es greift nicht auf Kamera, Mikrofon oder Standort zu.

WasWo
Ihre ZeichnungenNur dort, wo Sie sie speichern (File → Save / Export).
Einstellungen und Listen%LocalAppData%\Icono (Windows-Taste+R, den Pfad eintippen): theme.txt (Ihr Design), recent.txt (zuletzt geöffnete Dateien), Library\ (Ihre Icon-Bibliothek), crash.log (Fehlerprotokoll).

Das Fehlerprotokoll crash.log entsteht nur bei einem unerwarteten Fehler und kann Dateinamen oder Pfade enthalten. Es bleibt auf Ihrem Gerät; schicken Sie es nur freiwillig mit, wenn Sie einen Fehler melden, und sehen Sie es vorher durch. Der Ordner kann jederzeit gelöscht werden.

Die Einträge Check for Updates, Website und Contact im Menü Help öffnen auf Ihren Klick den Browser oder Ihr E-Mail-Programm; erst dann findet eine Verbindung statt, durch diese Programme. Das Handbuch, die Testbedingungen und der Datenschutzhinweis öffnen sich lokal aus dem Installationsordner in Ihrem Standard-Webbrowser (ohne Internet).

Enthalten Ihre Zeichnungen personenbezogene Daten Dritter (zum Beispiel Namen in einem Plankopf), sind Sie für den Umgang damit verantwortlich. Schicken Sie solche Zeichnungen nicht an den Hersteller.

Der vollständige Datenschutzhinweis: Datenschutz.txt im Installationsordner (auch beim Installieren angezeigt).

13. Sicherheit

  • Keine Netzwerkzugriffe durch das Programm; keine Hintergrunddienste.
  • Dateien von außen sind „fremde Daten“: SVG-Dateien werden ohne DTD und ohne Entitäten gelesen (Schutz vor „Billion Laughs“ und dem Auslesen lokaler Dateien); es wird nichts von Datenträger oder Netz nachgeladen. SVG bis 20 MB, Dokumente bis 512 MB und Bilder bis 64 MB werden angenommen, größere abgelehnt.
  • Nur feste Adressen werden geöffnet (Projektseite, bitbins.de, Kontakt-Mail), nie Adressen aus Dokumenten.
  • Der Installer ist nicht signiert (Testversion): Prüfen Sie die Herkunft und die Prüfsumme (SHA-256). Laden Sie icono nur von Ihrem Ansprechpartner.
  • Sicherheitslücken melden Sie bitte vertraulich an info@bitbins.de (siehe auch SECURITY.md im Projekt).
