icono 0.1.0-test.1 - Hinweise für Tester / Notes for testers
============================================================

DEUTSCH
-------

Danke, dass Sie icono testen!

Systemvoraussetzungen
  - Windows 10 (Version 1809 oder neuer) oder Windows 11, 64 Bit
  - rund 200 MB freier Speicher; keine weitere Software nötig (alles ist enthalten)
  - Internet wird nicht gebraucht

Installation
  1. ICONO-Setup-0.1.0-test.1.exe doppelt anklicken.
  2. Windows zeigt eventuell "Der Computer wurde durch Windows geschützt" (SmartScreen). Das liegt daran, dass die Testversion noch nicht
     digital signiert ist. Klicken Sie auf "Weitere Informationen" und dann auf "Trotzdem ausführen". Prüfen Sie vorher, dass die Datei von mir
     kommt; die Prüfsumme (SHA-256) steht in der Datei SHA256.txt, die ich mitgeschickt habe.
  3. Sprache wählen, Testbedingungen und Datenschutzhinweis lesen, installieren. Es werden keine Administratorrechte gebraucht (Installation
     nur für Ihr Benutzerkonto).

Was ich gern von Ihnen wüsste
  - Stürzt das Programm ab oder zeigt es eine Fehlermeldung?
  - Passiert etwas anderes, als Sie erwartet haben (Wände zeichnen, Längen eingeben, Objekte aus der Liste OBJECTS, Texte, Auswahl, Speichern und
    Öffnen, Export, Drucken)?
  - Was ist unverständlich oder umständlich?

So melden Sie einen Fehler (per E-Mail an info@bitbins.de)
  - Was haben Sie getan (Schritte), was haben Sie erwartet, was ist passiert? Ein Screenshot hilft sehr.
  - Version: Menü Help > About icono
  - Bei einem Absturz: die Datei crash.log (Windows-Taste + R, dann %LocalAppData%\Icono eingeben). Sie enthält keine Zeichnung, aber
    technische Angaben und manchmal Dateinamen; schauen Sie bitte hinein, bevor Sie sie senden.
  - Senden Sie keine Zeichnungen mit persönlichen Daten Dritter.

Ihre Daten
  icono sendet nichts und braucht kein Internet. Mehr in Datenschutz.txt. Ihre Zeichnungen speichern Sie selbst (Datei > Save). Sichern Sie
  wichtige Dateien, die Testversion kann Fehler haben.

Deinstallieren
  Windows-Einstellungen > Apps > icono > Deinstallieren (oder Startmenü > icono > icono deinstallieren). Dabei können Sie wählen, ob Ihre
  Einstellungen und das Fehlerprotokoll mit gelöscht werden.

Bekannt
  - Die Testversion ist nicht digital signiert (SmartScreen-Hinweis, siehe oben).
  - "Check for Updates" im Menü Help öffnet nur eine Webseite; Updates schicke ich Ihnen als neues Installationsprogramm.


ENGLISH
-------

Thank you for testing icono!

Requirements
  - Windows 10 (version 1809 or newer) or Windows 11, 64-bit
  - about 200 MB free space; no other software needed (everything is included)
  - no internet needed

Installation
  1. Double-click ICONO-Setup-0.1.0-test.1.exe.
  2. Windows may show "Windows protected your PC" (SmartScreen) because the test version is not digitally signed yet. Click "More info" and then
     "Run anyway". Please first check that the file comes from me; its checksum (SHA-256) is in SHA256.txt, which I sent along.
  3. Choose a language, read the test terms and the privacy notice, install. No administrator rights are needed (installation for your user
     account only).

What I would like to know
  - Does the program crash or show an error?
  - Does anything differ from what you expected (drawing walls, typing lengths, objects from the OBJECTS list, text, selecting, saving and
    opening, export, printing)?
  - What is unclear or awkward?

How to report a problem (by e-mail to info@bitbins.de)
  - What did you do (steps), what did you expect, what happened? A screenshot helps a lot.
  - Version: menu Help > About icono
  - For a crash: the file crash.log (Windows key + R, then type %LocalAppData%\Icono). It contains no drawing but technical details and sometimes
    file names; please look through it before you send it.
  - Do not send drawings with personal data of third parties.

Your data
  icono does not send anything and needs no internet. More in Privacy.txt. You save your drawings yourself (File > Save). Back up important
  files, the test version can contain errors.

Uninstall
  Windows Settings > Apps > icono > Uninstall (or Start menu > icono > Uninstall icono). You can choose whether your settings and the error log
  are deleted as well.

Known
  - The test version is not digitally signed (SmartScreen notice, see above).
  - "Check for Updates" in the Help menu only opens a web page; I will send updates as a new installer.
